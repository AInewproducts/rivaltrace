# RivalTrace 30-day SEO/GEO execution

Updated: 2026-10-29

## Outcome

Build discoverability around one defensible topic: manual, evidence-first beauty competitor research. The site must never imply live crawling, automatic monitoring, historical data, customer impact, or paid functionality that the current product does not provide.

## Week 1 — publish and make the structure crawlable

- Release the 107-URL sitemap: 90 editorial resources, 6 free tool pages, the pricing page, and the existing core pages.
- Confirm every public URL returns 200, declares one canonical URL, appears once in the sitemap, and is reachable through internal links.
- Publish the four internal-link pathways: baseline, pricing, offers, and reporting.
- Validate FAQ structured data on the homepage and five calculator pages. FAQ visibility is useful to readers; rich-result display is never promised.
- Submit the new sitemap in Google Search Console only after the public build is verified.

Success evidence: deployment commit, live HTTP checks, sitemap count, Search Console submission time. Search impressions are reported separately and only when Search Console shows them.

## Week 2 — earn the first relevant citations

- Prepare five manual outreach targets with a real editorial fit: independent beauty founder newsletters, DTC operations blogs, Shopify beauty communities, competitive-intelligence roundups, and ecommerce pricing resources.
- Lead with one useful asset, not the product subscription: the price-tracking CSV, one calculator, or the cited Summer Fridays example.
- Personalize each note around an existing article or resource gap. Do not claim a partnership, placement, or result before it exists.
- Send no outreach without owner approval of the target list and final message.

Success evidence: approved targets, messages sent, replies, and live referring URLs. Drafts and sends are different statuses.

## Week 3 — improve pages from real query evidence

- Export Search Console query/page data for the previous 28 days.
- Promote only pages with evidence: queries with impressions but weak click-through, or pages close to page-one visibility.
- Rewrite title/description only when the current query and landing page genuinely match.
- Add one concise answer block to pages that receive recurring question-shaped queries; keep the source and product boundary visible.
- Avoid new synonym pages. Create a new page only when it answers a different user task and can be materially more useful than an existing page.

Success evidence: before/after title, affected URL, query evidence, and annotation date. Rankings and clicks remain observational, not guaranteed outcomes.

## Week 4 — consolidate and choose the next cluster

- Compare indexed pages, impressions, clicks, CTR, average position, free-tool starts, pricing views, checkout starts, and PayPal lifecycle status.
- Treat subscription `CREATED` or `APPROVAL_PENDING` as an incomplete funnel, not revenue. Count revenue only from confirmed payment evidence.
- Merge or noindex pages with no distinct task, no internal purpose, and no search evidence after a reasonable observation window.
- Select the next cluster from real demand: price tracking, promotion arithmetic, pack-size normalization, shipping thresholds, or reporting templates.
- Produce a one-page monthly review with verified figures, evidence gaps, and the three highest-leverage changes for the next month.

## GEO answer design

- Each answer-oriented page starts with a direct definition or task answer, then shows method, example, source requirements, limitations, and a relevant free tool.
- Entity language stays consistent: RivalTrace is an evidence-first beauty competitor monitoring product; the current workflow is manual and browser-local.
- `llms.txt`, schema.org markup, canonical URLs, dated editorial notes, and source-linked examples must agree with visible page copy.
- No fabricated citations, snapshots, customer outcomes, usage numbers, or automation claims.

## Measurement guardrails

- Acquisition: Search Console impressions, clicks, CTR, position, indexed URLs, referring domains.
- Activation: snapshot start/completion and calculator use when analytics events exist.
- Commercial: pricing view, checkout start, PayPal approval, activated subscription, captured payment.
- Revenue: only settled or provider-confirmed payments. If no such evidence exists, report `$0 confirmed revenue`.
